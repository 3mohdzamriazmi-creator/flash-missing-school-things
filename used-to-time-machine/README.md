# Then & Now — Used to Time Machine
An original English grammar lesson and game based on the supplied textbook topic: affirmative used to and negative didn’t use to, both followed by the base verb.

Start with the short Malay-narrated video with Malay captions (assets/lesson.webm). Replay/pause with normal video controls. A full readable lesson is provided under the video; pupils can proceed after watching or reading. Then play 20 original missions across School, Park, Town and Home. Read THEN/NOW clues and choose the phrase or base verb that completes the sentence. Friendly explanations, Malay hints, unlimited retries and no countdown.

Marks /20 count correct first answers. Results save on this browser/device, with name/class; Google Sheets recording and Class Top 5 are prepared; the web app endpoint is configured. Live saving and rankings still need verification on GitHub Pages. Replaying the game creates a new attempt. No existing game endpoints are reused. Keep personal-use practice results on a shared classroom device in mind.

Files: index.html, style.css, game.js, questions.js, recording.js and the entire assets/ folder. Keep relative paths together. Upload into a new used-to-time-machine/ subfolder; preserve existing root games. Nothing published automatically.

Narration uses the Mac’s Amira (Malay) text-to-speech voice. Video artwork is generated using browser canvas; no copied textbook cartoons or external video embeds. WebM playback depends on browser support; the text lesson remains available.

The video explanations and lesson transcript are in Bahasa Melayu; English grammar examples are retained. The practice game remains in English with Malay hints.

Recording setup: teacher-setup/used-to-time-machine/Code.gs and SETUP.md. First-answer marks /20, best score per pupil within their class, five leaderboard entries and own rank. Live saving must be checked after deployment.
