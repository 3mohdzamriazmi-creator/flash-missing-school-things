# Spider Adventure — Year 1, Unit 3 Pet Show
Based on the supplied two-page “The spider” lesson. Eight short illustrated story cards introduce Flash, Misty, Thunder, Whisper and the spider. Twenty activities cover the four yes/no reading statements, the speaker of “Touch him, Misty”, picture vocabulary, beautiful/clever/amazing, under/on/in, story feelings, and Tim/Kim short-i rhyme practice.

The textbook characters/story are referenced for comprehension. All game illustrations are newly drawn SVGs; the textbook scan and its artwork are not included. Extra garden location tasks are practice activities, not additional textbook story events. The phonics pair Tim/Kim comes from the supplied page. No real-world animal handling is required.

English read-aloud uses the browser speech engine where available; English text and Malay help remain visible. Optional cheerful sound effects, no countdown, keyboard/touch buttons, reduced-motion support. Answer feedback permits retries. First correct attempt earns 1 mark, maximum 20. Completing any activity adds a friendship-web thread, independent of the mark.

Pupil name/class, local result storage and Google Sheets/Class Top 5 recording code are included. The new web app endpoint is configured; live saving and rankings still need verification on GitHub Pages. Teacher setup: ../teacher-setup/year-1-spider-adventure/. Rankings use best score per pupil in the same class, ties share rank, top five pupils plus own rank. Live saving must be verified after the new Apps Script deployment and GitHub upload. No existing game endpoint is reused.

Open index.html locally. Keep index.html, style.css, data.js, art.js, game.js, recording.js and README.md together in year-1-spider-adventure/. No external asset downloads or build are required. Upload this new subfolder only, preserving root files and all previous games. Nothing is published automatically.
